# Roadmap

## v0.1 (Current)

- [x] HCT color token engine (`Dark`, `Light`, `AMOLED`, 9 schemes, contrast controls, per-role overrides)
- [x] 19 pre-built skins across 10 color families (Brown, Red, Blue, Yellow, Green, Pink, Purple, Orange, Black, White)
- [x] OS wallpaper/accent color sync (`m3vlc sync` / `--watch`)
- [x] Local Theme Studio (`m3vlc studio`) with per-role pickers and automatic VLC restart
- [x] Main player, playlist side sheet, mini-player, equalizer, control center, fullscreen HUD, and about dialog

## Planned

- [ ] Background auto-sync installer (`systemd --user` / Windows Task Scheduler)
- [ ] Community palette JSON registry (`palettes/*.json`)
- [ ] Standalone desktop bundle for `m3vlc studio` (no Python required)
- [ ] VLC 4.0 QML theming support once upstream APIs stabilize
